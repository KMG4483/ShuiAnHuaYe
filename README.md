# 水岸花野 AI 运营助手 · 网页版

纯静态网页，可直接上传到 GitHub Pages。

## 一、本地怎么用

1. 打开桌面程序 → 「手机版」→ 启动服务（默认 8765）；
2. 双击本目录的 `index.html` 用浏览器打开（或放进同目录的服务器）；
3. 点右上角「连接设置」，填 `http://电脑IP:8765`，保存即可。

> 如果网页和 API 不在同一个地址（例如 GitHub Pages），必须填完整地址，并确保该地址能被外网访问。

## 二、上传 GitHub Pages

1. 新建仓库，把 `网页版` 目录里的文件全部上传到仓库根目录；
2. Settings → Pages → Source 选 `main` / 根目录；
3. 打开 `https://你的用户名.github.io/仓库名/`；
4. 第一次点「连接设置」，填你的 API 地址（内网穿透/云服务器）。

## 三、让外网能访问 API（关键）

网页只是“壳”，数据来自你电脑上的程序。外网访问需要把 8765 端口暴露出去，任选其一：

- **Cloudflare Tunnel**：`cloudflared tunnel --url http://127.0.0.1:8765`，会得到一个 https 地址，填到网页「连接设置」；
- **frp / nps**：用你自己的云服务器做中转；
- **云服务器部署**：把桌面程序跑在服务器上，开放 8765（注意加访问令牌）。

> 手机版服务本身没有登录验证，暴露到公网前请务必只在可信网络使用，或加一层反向代理密码。

## 四、目录

- `index.html` 页面结构（手机/电脑两套布局）
- `styles.css` 响应式样式（≤820px 自动切手机版）
- `app.js` 数据请求与渲染
- `assets/logo.png` 图标
